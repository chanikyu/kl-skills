# Wiki de kl-skills

Skills y hook gates para Claude Code, instalados juntos. Las skills dicen cómo se hace un trabajo; los hook
gates comprueban que se hizo; la wiki guarda lo aprendido.

## Skills

**Conocimiento**

| Skill | Qué hace |
| --- | --- |
| [llm-wiki-docs](llm-wiki-docs-es.md) | Guarda lo que aprendes en una wiki, una página por tema, con un índice y un registro |
| [wiki-recall](wiki-recall-es.md) | Busca páginas relacionadas de la wiki con cada mensaje y las usa en la respuesta |
| [graph-doc-memory](graph-doc-memory-es.md) | Dibuja toda la wiki como un grafo en el navegador, cuando lo pides |
| [research-to-wiki](research-to-wiki-es.md) | Registra la investigación con el tipo de estudio de cada fuente y cuánto se leyó |

**Escritura y código**

| Skill | Qué hace |
| --- | --- |
| [natural-answering](natural-answering-es.md) | Escribe sin saltarse términos, puntos de comparación ni el paso hasta la conclusión |
| [readable-code](readable-code-es.md) | Los nombres dicen qué contienen; los comentarios, por qué |
| [no-hardcoding](no-hardcoding-es.md) | Mantiene listas, rutas y umbrales fuera del código |

**Trabajo**

| Skill | Qué hace |
| --- | --- |
| [task-checklist](task-checklist-es.md) | Convierte cada instrucción en una lista de comprobación y solo termina cuando todos los puntos están hechos |
| [planner](planner-es.md) | Planifica según el campo y el horizonte, y avisa del trabajo que se desvía del plan |
| [pipeline-debug](pipeline-debug-es.md) | Busca la primera etapa que salió mal, no la línea que falló |
