# kl-skills wiki

Claude Code 用のスキルとフックゲートを、まとめてインストールする。スキルは仕事のやり方を示し、フックゲートはそれが実際に行われたかを確かめ、wiki は学んだことを残す。

## スキル

**知識**

| スキル | 何をするか |
| --- | --- |
| [llm-wiki-docs](llm-wiki-docs-ja.md) | 学んだことを wiki に残す。1トピック1ページで、索引とログを付ける |
| [wiki-recall](wiki-recall-ja.md) | メッセージごとに関連する wiki ページを探し、回答に使う |
| [graph-doc-memory](graph-doc-memory-ja.md) | 頼まれたときに、wiki 全体をブラウザでグラフとして描く |
| [research-to-wiki](research-to-wiki-ja.md) | 調査を、出典ごとの研究の種類とどこまで読んだかを付けて記録する |

**文章とコード**

| スキル | 何をするか |
| --- | --- |
| [natural-answering](natural-answering-ja.md) | 用語、比較基準、結論への一歩を省かずに書く |
| [readable-code](readable-code-ja.md) | 名前は中身を表し、コメントは理由を表す |
| [no-hardcoding](no-hardcoding-ja.md) | リスト、パス、しきい値をコードに書き込まない |

**作業**

| スキル | 何をするか |
| --- | --- |
| [task-checklist](task-checklist-ja.md) | すべての指示をチェックリストにし、全項目が終わったときだけ完了する |
| [planner](planner-ja.md) | 分野と期間に沿って計画し、計画から外れた作業を指摘する |
| [pipeline-debug](pipeline-debug-ja.md) | 失敗した行ではなく、最初に誤った段階を見つける |
