# kl-skills 위키

`kl-skills` 는 Claude Code 용 스킬과 훅 게이트를 한 번에 설치한다. 스킬(= Claude 에게 일하는 방법을 알려 주는 설명서)은
일을 어떻게 하는지 말한다. 훅 게이트(= 정해진 순간마다 저절로 도는 검사)는 그 일을 정말 했는지 확인한다.
위키(= 주제마다 한 페이지씩 쓰는 지식 노트 모음)는 알게 된 것을 남긴다.

## 스킬

**지식**

| 스킬 | 하는 일 |
| --- | --- |
| [llm-wiki-docs](llm-wiki-docs-ko.md) | 알게 된 것을 위키에 남긴다. 주제 하나에 한 페이지이고, 목차와 기록이 함께 있다 |
| [wiki-recall](wiki-recall-ko.md) | 메시지마다 관련된 위키 페이지를 찾아 답에 쓴다 |
| [graph-doc-memory](graph-doc-memory-ko.md) | 부탁하면 위키 전체를 브라우저에 그래프로 그린다 |
| [research-to-wiki](research-to-wiki-ko.md) | 조사한 것을 남긴다. 출처마다 연구 종류와 얼마나 읽었는지를 적는다 |

**글과 코드**

| 스킬 | 하는 일 |
| --- | --- |
| [natural-answering](natural-answering-ko.md) | 용어, 비교 기준, 결론에 이르는 단계를 빼먹지 않고 쓴다 |
| [readable-code](readable-code-ko.md) | 이름은 담긴 것을 말하고, 주석은 이유를 말한다 |
| [no-hardcoding](no-hardcoding-ko.md) | 목록, 경로, 임계값(= 판단을 가르는 기준 숫자)을 코드 밖에 둔다 |

**일**

| 스킬 | 하는 일 |
| --- | --- |
| [task-checklist](task-checklist-ko.md) | 모든 지시를 체크리스트로 바꾸고, 모든 항목이 끝나야 마친다 |
| [planner](planner-ko.md) | 분야와 기간에 맞춰 계획하고, 계획에서 벗어난 일을 알린다 |
| [pipeline-debug](pipeline-debug-ko.md) | 실패한 줄이 아니라, 처음 잘못된 단계를 찾는다 |
