# kl-skills wiki

为 Claude Code 准备的技能和钩子检查，一起安装。技能说明一项工作该怎么做；钩子检查确认它确实做了；wiki
保存学到的东西。

## 技能

**知识**

| 技能 | 作用 |
| --- | --- |
| [llm-wiki-docs](llm-wiki-docs-zh.md) | 把学到的东西存进 wiki，一个主题一页，并附带索引和日志 |
| [wiki-recall](wiki-recall-zh.md) | 为每条消息找出相关的 wiki 页面，并在回答中用上 |
| [graph-doc-memory](graph-doc-memory-zh.md) | 在你要求时，把整个 wiki 画成浏览器里的图 |
| [research-to-wiki](research-to-wiki-zh.md) | 记录调研结果，并注明每个来源的研究类型和读了多少 |

**写作与代码**

| 技能 | 作用 |
| --- | --- |
| [natural-answering](natural-answering-zh.md) | 写作时不跳过术语、比较基准，也不跳过通向结论的那一步 |
| [readable-code](readable-code-zh.md) | 名字说明它装的是什么；注释说明为什么 |
| [no-hardcoding](no-hardcoding-zh.md) | 不让列表、路径和阈值写死在代码里 |

**工作**

| 技能 | 作用 |
| --- | --- |
| [task-checklist](task-checklist-zh.md) | 把每条指令变成清单，只有每一项都完成才结束 |
| [planner](planner-zh.md) | 按领域和时间跨度做计划，并标出偏离计划的工作 |
| [pipeline-debug](pipeline-debug-zh.md) | 找出第一个出错的阶段，而不是报错的那一行 |
