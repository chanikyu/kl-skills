## スキル、フックゲート、wiki

<img src="../../assets/parts.png" alt="あなたのメッセージは Claude Code に届く。Claude Code はスキルを読み、フックゲートのチェックを受け、学んだことを wiki に残す。" width="100%" />

- **スキル**は仕事のやり方を示す。Claude Code は、会話がスキルの説明に合うとそのスキルを読み込む。合うかどうかの判断はモデル自身が行うため、必ず読み込まれるとは限らない。
- **フックゲート**は、誰かが覚えているかどうかに関係なく、決まった時点で動く。`skill-match` は上の穴をふさぐ。すべてのメッセージを各スキルの発動語と照らし合わせ、合うスキルの名前を挙げる。発動語は英語と韓国語だけなので、ほかの言語では Claude がスキルの説明を自分で照らし合わせる。
- **wiki** は学んだことを1トピック1ページで残し、`wiki-recall` がそれを呼び戻す。

## フックゲート

| いつ | ゲート | 何をするか | 回答を差し戻すか |
| --- | --- | --- | --- |
| セッション開始時 | `session-start` | バナーを表示する | — |
| メッセージが届いたとき | `wiki-recall` | 関連する wiki ページを添える | — |
| メッセージが届いたとき | `skill-match` | このメッセージに合うスキルの名前を挙げる | — |
| メッセージが届いたとき | `checklist-start` | この指示のチェックリストをどこに書くかを伝える | — |
| ファイルが書かれたとき | `wiki-index-check` | 索引に載っていない wiki ページを指摘する | — |
| ファイルが書かれたとき | `wiki-graph` | wiki のグラフを描き直す | — |
| ファイルが書かれたとき | `prose-check` | wiki ページの読みにくい箇所を指摘する | — |
| ファイルが書かれたとき | `code-check` | あいまいな Python の名前と docstring の欠落を指摘する | — |
| ファイルが書かれたとき | `plan-drift` | 計画の枠組みとずれをチェックする | — |
| Bash が動いたとき | `after-bash` | シェルで行われた wiki の編集とコミットを拾う | — |
| 回答が終わるとき | `wiki-sync` | ページがどう編集されたかに関係なく、グラフを最新にする | — |
| 回答が終わるとき | `answer-check` | 回答をチェックする: 同じ質問の聞き直し、作業報告、長さ、文章、分野の用語 | 1回 |
| 回答が終わるとき | `checklist-check` | チェックリストの全項目が終わっているかをチェックする | 1回 |

## 回答が差し戻されるとき

回答があなたに届く前に Claude へ差し戻せるゲートは2つある。`answer-check` と `checklist-check` である。そのとき Claude Code は理由とともに `Stop hook feedback:` を表示し、Claude は回答を直すか、残っている項目を終わらせる。どちらのゲートも差し戻すのは**1ターンに1回**だけである。2回目はまだ残っているものを報告するだけなので、ターンが無限ループすることはない。

## ゲートが判断できないとき

そのターンを通す。クラッシュするゲートは、そのイベントが起きるすべてのセッションを壊してしまう。そのため、どのゲートも理解できない入力に対してはきれいに終了する。
