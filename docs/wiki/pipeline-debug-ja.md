# pipeline-debug

コードが失敗したり誤った結果を出したりしたとき、問題が表に出た行を直すのではなく、パイプラインをさかのぼって原因を突き止める。

## Claude での使い方

「このエラーの原因を見つけて」と言う。エラー、トレースバック、失敗した実行には、`skill-match` がこのスキルの名前を挙げる。

## 何をするか

1. データが通った段階を書き出す。
2. 各段階に入ったものと出てきたもの — 件数、列、いくつかの実際の値 — を、期待していたものと比べる。
3. 出力が誤っている最初の段階が原因である。エラーはたいてい、それより後ろで現れる。
4. その段階で問題を再現し、失敗するチェックで固定し、そこで直してから、それより後のすべての段階をもう一度実行する。

## ファイルとスクリプト

| スクリプト | すること |
| --- | --- |
| `probe.py [--rows N] FILE ...` | 段階の間で受け渡されるファイルの行、列、空欄、最初の数行を表示する |

## 制限

中間ファイルが必要である。段階の間に何も残さないパイプラインは、中間ファイルを保存するようにしてもう一度実行しなければならない。
