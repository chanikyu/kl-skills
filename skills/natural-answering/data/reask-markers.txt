# 되묻는 말투. 앞 답이 질문에 닿지 않았을 때 사람이 다시 요청하며 쓰는 말이다.
# 한 줄에 정규식 하나. 사람 메시지에서 하나라도 찾으면 "다시 요청" 으로 본다.
# 출처: 2026-11-11 kl-skills 대화에서 실제로 되물은 메시지들
#   "그러니까 뭔지를 왜 안 알려주는데????" / "아니.... 내 질문 이해가 안되니????"
#   "뭔 소리인지 모르겠다니까???"
# 의문사('왜', '무엇')는 여기 넣지 않는다. 새 질문에도 늘 들어가서, 한 번만 요청한 것과
# 다시 요청한 것을 가르지 못한다(2026-11-11 오탐의 원인).
^\s*아니(?:[\s.,!?…~]|$)

(?:했|말했|물었)잖
